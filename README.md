# 전자제품 고객 리뷰 AI 분석 CLI

전자제품 리뷰 데이터를 기반으로 제품별 고객 반응을 분석하고,
AI API를 활용하여 **감정 분석, 키워드 추출, 리뷰 요약, 개선 제안, 대시보드 시각화**를 제공하는 CLI 기반 리뷰 분석 시스템입니다.

사용자는 쇼핑몰처럼 제품을 선택하여 리뷰를 확인하고, 원하는 제품에 대해 AI 분석을 실행할 수 있습니다.

---

# 1. 프로젝트 개요

온라인 쇼핑몰에는 하나의 제품에도 수백~수천 개의 고객 리뷰가 작성됩니다.

하지만 모든 리뷰를 사람이 직접 읽고 제품의 장점과 문제점을 파악하기에는 많은 시간이 필요합니다.

본 프로젝트에서는 CSV 또는 Excel 형태의 리뷰 데이터를 수집하고, AI API를 이용하여 각 리뷰의 감정을 분석합니다.

또한 여러 리뷰를 종합하여 다음과 같은 정보를 자동으로 제공합니다.

* 긍정 / 중립 / 부정 감정 분석
* AI 감정 신뢰도 점수
* 주요 긍정 키워드
* 주요 부정 키워드
* 주요 칭찬 및 불만 사항
* 전체 리뷰 요약
* 제품 개선 제안
* 제품별 리뷰 통계
* 시각화 대시보드

---

# 2. 전체 시스템 흐름

```text
CSV / Excel 리뷰 데이터
        ↓
리뷰 데이터 Import
        ↓
원본 데이터 저장
raw_reviews.jsonl
        ↓
데이터 정제
        ↓
정제 데이터 저장
clean_reviews.jsonl
        ↓
제품 목록 및 리뷰 조회
        ↓
사용자가 제품 선택
        ↓
Gemini AI 리뷰 분석
        ↓
긍정 / 중립 / 부정 분류
+ 신뢰도 점수
        ↓
AI 키워드 / 요약 / 개선 제안
        ↓
extracts.jsonl 저장
        ↓
통계 / 대시보드 / 리포트
        ↓
CSV / Excel / JSONL Export
```

# 3. CLI 구성

본 프로젝트는 Python의 `argparse`를 이용하여 서브커맨드 기반 CLI로 구현되어 있습니다.

지원하는 주요 서브커맨드는 다음과 같습니다.

* `import` : CSV / Excel 리뷰 데이터 가져오기
* `clean` : 리뷰 데이터 정제
* `analyze` : AI 감정 분석
* `extract` : AI 키워드 및 요약 추출
* `list` : 리뷰 목록 조회
* `show` : 특정 리뷰 상세 조회
* `stats` : 전체 리뷰 통계 조회
* `dashboard` : 분석 대시보드 생성
* `export` : 분석 데이터 내보내기

일반 사용자는 명령어를 직접 입력하지 않아도 `main.py`를 실행하여 쇼핑몰 형태의 메뉴를 사용할 수 있습니다.

# 4. 리뷰 데이터 수집

CSV 또는 Excel 파일에서 고객 리뷰 데이터를 가져옵니다.

리뷰 데이터에서 사용하는 주요 항목은 다음과 같습니다.

* 리뷰 텍스트
* 고객 별점
* 작성일
* 제품명
* 브랜드

리뷰 텍스트는 필수 데이터이며, 나머지 항목은 데이터에 따라 선택적으로 사용할 수 있습니다.

수집한 데이터는 바로 수정하지 않고 원본 상태 그대로 별도 저장합니다.

```text
data/raw_reviews.jsonl
```

이를 통해 원본 데이터와 정제된 데이터를 분리하여 관리합니다.

---

# 5. 데이터 정제

수집한 원본 리뷰는 AI 분석에 사용하기 전에 정제 과정을 수행합니다.

주요 정제 규칙은 다음과 같습니다.

* 리뷰 텍스트 필수값 확인
* 불필요한 공백 제거
* 텍스트 정규화
* 고객 별점 1~5 범위 검증
* 리뷰 작성일 형식 통일
* 지나치게 짧은 리뷰 필터링
* 중복 리뷰 확인

정제가 완료된 데이터는 다음 파일에 별도로 저장합니다.

```text
data/clean_reviews.jsonl
```

---

# 6. 중복 리뷰 처리

동일한 리뷰가 여러 번 수집되는 것을 방지하기 위해 중복 처리 정책을 적용합니다.

설정에 따라 다음 방식 중 하나를 사용할 수 있습니다.

### Skip

동일한 리뷰가 이미 존재하는 경우 기존 데이터를 유지하고 새로운 데이터는 저장하지 않습니다.

### Upsert

동일한 리뷰가 존재할 경우 새로운 데이터로 갱신합니다.

중복 처리 방식은 `config.json`에서 관리할 수 있습니다.

# 7. 제품 목록 및 리뷰 조회

사용자는 CLI 화면에서 쇼핑몰처럼 제품 목록을 확인할 수 있습니다.

제품 목록에서는 다음 정보를 제공합니다.

* 제품명
* 브랜드
* 리뷰 수
* 평균 고객 별점

제품을 선택하면 해당 제품의 리뷰를 확인할 수 있습니다.

예시:

```text
============================================================
CRX-322 CD Receiver
============================================================

평균 별점    : ★★★★☆ 4.3
리뷰 수      : 120건
AI 분석 상태 : 30 / 120건

[최근 리뷰]

★★★★★
음질이 좋고 사용하기 편리합니다.

★★★☆☆
기능은 괜찮지만 연결이 가끔 끊깁니다.

------------------------------------------------------------

1. 전체 리뷰 보기
2. Gemini AI 리뷰 분석 / 고객 인사이트
3. 부정 리뷰 보기
4. 긍정 리뷰 보기
5. 제품 대시보드
0. 이전 메뉴
```

# 8. AI 기반 감정 분석

사용자가 제품에서 AI 리뷰 분석 기능을 선택하면 해당 제품의 리뷰 텍스트를 Gemini API에 전달합니다.

AI는 각 리뷰를 다음 세 가지 감정으로 분류합니다.

* Positive : 긍정
* Neutral : 중립
* Negative : 부정

또한 AI가 해당 감정 판단을 얼마나 확신하는지 `0.0 ~ 1.0` 범위의 신뢰도 점수를 함께 반환합니다.

예시:

```text
리뷰
"음질은 정말 좋지만 블루투스 연결이 가끔 끊깁니다."

AI 분석 결과
감정 : Negative
신뢰도 : 0.87
```

AI 분석 결과는 메모리에서만 사용하는 것이 아니라 정제된 리뷰 파일에 영구 저장됩니다.

```text
data/clean_reviews.jsonl
```

저장되는 주요 AI 분석 항목은 다음과 같습니다.

```text
sentiment
confidence
analysis_provider
analyzed_at
```

# 9. AI 분석 대상 선택

AI 감정 분석 시 분석할 리뷰의 범위를 선택할 수 있습니다.

### 전체 리뷰 분석

해당 조건에 맞는 리뷰 전체를 분석합니다.

### 특정 리뷰 분석

리뷰 ID를 지정하여 특정 리뷰만 AI 분석할 수 있습니다.

### 미분석 리뷰 분석

아직 AI 감정 분석이 수행되지 않은 리뷰만 대상으로 분석할 수 있습니다.

이를 통해 이미 분석된 리뷰에 대한 불필요한 API 호출을 줄일 수 있습니다.

# 10. API 오류 처리

외부 AI API 사용 중 네트워크 오류 또는 API 오류가 발생할 수 있습니다.

이 경우 전체 프로그램을 중단하지 않고 오류가 발생한 리뷰를 로그에 기록한 후 다음 리뷰 분석을 계속 수행합니다.

주요 로그 레벨은 다음과 같습니다.

* INFO
* WARNING
* ERROR

로그 파일은 다음 위치에 저장됩니다.

```text
logs/app.log
```

# 11. AI 키워드 및 리뷰 요약

리뷰별 감정 분석이 완료되면 여러 개의 리뷰를 종합하여 Gemini AI에 추가 분석을 요청합니다.

주요 추출 항목은 다음과 같습니다.

### 긍정 키워드

고객 리뷰에서 반복적으로 나타나는 제품의 장점을 추출합니다.

예시:

```text
음질
디자인
배터리
사용 편의성
블루투스
```

### 부정 키워드

고객 리뷰에서 반복적으로 나타나는 불편 사항과 문제점을 추출합니다.

예시:

```text
연결 끊김
충전 문제
무게
높은 가격
내구성
```

### 전체 리뷰 요약

여러 고객 리뷰를 AI가 종합하여 제품에 대한 전체적인 고객 반응을 요약합니다.

예시:

```text
전반적으로 음질과 디자인에 대한 만족도가 높으며
사용 편의성 역시 긍정적으로 평가되고 있습니다.

다만 일부 리뷰에서는 블루투스 연결 안정성과
제품 가격에 대한 불만이 나타났습니다.
```

### 개선 제안

부정 리뷰와 반복적으로 나타나는 고객 불만을 기반으로 제품 개선 방향을 제안합니다.

예시:

```text
- 블루투스 연결 안정성 개선
- 제품 가격 경쟁력 검토
- 충전 방식 개선
```

# 17. 고객 별점과 AI 감정 비교

고객 별점과 AI 감정 분석 결과는 서로 다른 값으로 관리합니다.

고객 별점은 고객이 쇼핑몰에서 직접 입력한 평가 점수이고, AI 감정은 실제 리뷰 내용을 AI가 분석한 결과입니다.

예:

```text
고객 별점
★★★★☆ 4점

리뷰
"제품은 괜찮지만 연결이 너무 자주 끊깁니다."

AI 분석
Negative

AI 신뢰도
0.91
```

이를 이용하여 고객이 입력한 별점과 실제 리뷰 내용 사이에 차이가 있는지도 확인할 수 있습니다.

# 21. 데이터 저장 구조

프로그램 종료 후에도 리뷰 및 AI 분석 결과를 유지하기 위해 JSONL 기반 영구 저장 방식을 사용합니다.

### raw_reviews.jsonl

CSV 또는 Excel에서 가져온 원본 리뷰 데이터를 저장합니다.

### clean_reviews.jsonl

정제가 완료된 리뷰와 각 리뷰의 AI 감정 분석 결과를 저장합니다.

### extracts.jsonl

제품별 또는 조건별 AI 키워드, 리뷰 요약, 개선 제안을 저장합니다.

이와 같이 원본 데이터와 정제 데이터, AI 종합 분석 데이터를 각각 분리하여 관리합니다.

# 22. 설정 관리

프로그램의 주요 설정은 `config.json`을 통해 관리합니다.

관리하는 주요 설정 항목은 다음과 같습니다.

* AI Provider
* AI 모델
* API Key 환경변수명
* API 요청 제한시간
* AI 분석 건수
* 중복 처리 정책
* 리뷰 최소 길이
* 대시보드 출력 옵션
* 한글 폰트 후보
* 출력 파일 경로

실제 Gemini API Key는 보안을 위해 `config.json`에 직접 작성하지 않고 `.env` 파일에 저장합니다.

```text
GEMINI_API_KEY=사용자_API_KEY
```

`.env` 파일은 `.gitignore`에 등록하여 GitHub에 업로드되지 않도록 관리합니다.

# 23. 모듈 구성

모든 기능을 하나의 Python 파일에 작성하지 않고 기능별로 모듈을 분리하였습니다.

주요 모듈은 다음과 같습니다.

```text
app/
├─ ai_client.py
├─ analytics.py
├─ cleaner.py
├─ config.py
├─ dashboard.py
├─ env.py
├─ exporter.py
├─ importer.py
├─ services.py
├─ shop.py
└─ storage.py
```

각 모듈의 역할은 다음과 같습니다.

### ai_client.py

Gemini API 호출 및 AI 응답 처리

### importer.py

CSV / Excel 데이터 가져오기

### cleaner.py

리뷰 데이터 정제

### storage.py

JSONL 데이터 저장 및 조회

### services.py

감정 분석 및 AI 키워드/요약 처리

### analytics.py

감정 비율, 평균 별점 등 통계 분석

### dashboard.py

Matplotlib 차트 및 리포트 생성

### exporter.py

CSV / Excel / JSONL 데이터 내보내기

### shop.py

제품 목록 및 쇼핑몰 형태 CLI 화면 처리

# 26. 프로젝트 핵심 기능

본 프로젝트는 단순히 리뷰 데이터를 조회하는 프로그램이 아니라 다음의 전체 과정을 CLI 환경에서 처리하는 것을 목표로 합니다.

```text
제품 선택
   ↓
고객 리뷰 조회
   ↓
Gemini AI 감정 분석
   ↓
긍정 / 중립 / 부정 분류
   ↓
AI 신뢰도 점수 저장
   ↓
주요 긍정 / 부정 키워드 추출
   ↓
고객 리뷰 전체 요약
   ↓
제품 개선사항 제안
   ↓
통계 분석
   ↓
대시보드 시각화
   ↓
리포트 및 데이터 Export
```

이를 통해 사용자는 수백 개의 고객 리뷰를 직접 읽지 않고도 특정 제품에 대한 고객 만족도, 주요 장점, 반복적인 불만 사항 및 개선 방향을 빠르게 파악할 수 있습니다.
