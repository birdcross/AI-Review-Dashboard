# 전자제품 고객 리뷰 AI 분석 CLI

전자제품 리뷰 데이터를 기반으로 제품별 고객 반응을 분석하고,
AI API를 활용하여 **감정 분석, 키워드 추출, 리뷰 요약, 개선 제안, 대시보드 시각화**를 제공하는 CLI 기반 리뷰 분석 시스템입니다.

사용자는 쇼핑몰처럼 제품을 선택하여 리뷰를 확인하고, 원하는 제품에 대해 AI 분석을 실행할 수 있습니다.

---

# 1. 프로젝트 개요

온라인 쇼핑몰에는 하나의 제품에도 수백~수천 개의 고객 리뷰가 작성됩니다.

하지만 모든 리뷰를 사람이 직접 읽고 제품의 장점과 문제점을 파악하기에는 많은 시간이 필요합니다.

본 프로젝트에서는 CSV 또는 Excel 형태의 리뷰 데이터를 수집하고, AI API를 이용하여 각 리뷰의 감정을 분석합니다.

또한 여러 리뷰를 종합하여 다음과 같은 정보를 자동으로 제공합니다.

* 긍정 / 중립 / 부정 감정 분석
* AI 감정 신뢰도 점수
* 주요 긍정 키워드
* 주요 부정 키워드
* 주요 칭찬 및 불만 사항
* 전체 리뷰 요약
* 제품 개선 제안
* 제품별 리뷰 통계
* 시각화 대시보드

---

# 2. 전체 시스템 흐름

```text
CSV / Excel 리뷰 데이터
        ↓
리뷰 데이터 Import
        ↓
원본 데이터 저장
raw_reviews.jsonl
        ↓
데이터 정제
        ↓
정제 데이터 저장
clean_reviews.jsonl
        ↓
제품 목록 및 리뷰 조회
        ↓
사용자가 제품 선택
        ↓
Gemini AI 리뷰 분석
        ↓
긍정 / 중립 / 부정 분류
+ 신뢰도 점수
        ↓
AI 키워드 / 요약 / 개선 제안
        ↓
extracts.jsonl 저장
        ↓
통계 / 대시보드 / 리포트
        ↓
CSV / Excel / JSONL Export
```

# 3. CLI 구성

본 프로젝트는 Python의 `argparse`를 이용하여 서브커맨드 기반 CLI로 구현되어 있습니다.

지원하는 주요 서브커맨드는 다음과 같습니다.

* `import` : CSV / Excel 리뷰 데이터 가져오기
* `clean` : 리뷰 데이터 정제
* `analyze` : AI 감정 분석
* `extract` : AI 키워드 및 요약 추출
* `list` : 리뷰 목록 조회
* `show` : 특정 리뷰 상세 조회
* `stats` : 전체 리뷰 통계 조회
* `dashboard` : 분석 대시보드 생성
* `export` : 분석 데이터 내보내기

일반 사용자는 명령어를 직접 입력하지 않아도 `main.py`를 실행하여 쇼핑몰 형태의 메뉴를 사용할 수 있습니다.

# 4. 리뷰 데이터 수집

CSV 또는 Excel 파일에서 고객 리뷰 데이터를 가져옵니다.

리뷰 데이터에서 사용하는 주요 항목은 다음과 같습니다.

* 리뷰 텍스트
* 고객 별점
* 작성일
* 제품명
* 브랜드

리뷰 텍스트는 필수 데이터이며, 나머지 항목은 데이터에 따라 선택적으로 사용할 수 있습니다.

수집한 데이터는 바로 수정하지 않고 원본 상태 그대로 별도 저장합니다.

```text
data/raw_reviews.jsonl
```

이를 통해 원본 데이터와 정제된 데이터를 분리하여 관리합니다.

---

# 5. 데이터 정제

수집한 원본 리뷰는 AI 분석에 사용하기 전에 정제 과정을 수행합니다.

주요 정제 규칙은 다음과 같습니다.

* 리뷰 텍스트 필수값 확인
* 불필요한 공백 제거
* 텍스트 정규화
* 고객 별점 1~5 범위 검증
* 리뷰 작성일 형식 통일
* 지나치게 짧은 리뷰 필터링
* 중복 리뷰 확인

정제가 완료된 데이터는 다음 파일에 별도로 저장합니다.

```text
data/clean_reviews.jsonl
```

---

# 6. 중복 리뷰 처리

동일한 리뷰가 여러 번 수집되는 것을 방지하기 위해 중복 처리 정책을 적용합니다.

설정에 따라 다음 방식 중 하나를 사용할 수 있습니다.

### Skip

동일한 리뷰가 이미 존재하는 경우 기존 데이터를 유지하고 새로운 데이터는 저장하지 않습니다.

### Upsert

동일한 리뷰가 존재할 경우 새로운 데이터로 갱신합니다.

중복 처리 방식은 `config.json`에서 관리할 수 있습니다.

# 7. 제품 목록 및 리뷰 조회

사용자는 CLI 화면에서 쇼핑몰처럼 제품 목록을 확인할 수 있습니다.

제품 목록에서는 다음 정보를 제공합니다.

* 제품명
* 브랜드
* 리뷰 수
* 평균 고객 별점

제품을 선택하면 해당 제품의 리뷰를 확인할 수 있습니다.

예시:

```text
============================================================
CRX-322 CD Receiver
============================================================

평균 별점    : ★★★★☆ 4.3
리뷰 수      : 120건
AI 분석 상태 : 30 / 120건

[최근 리뷰]

★★★★★
음질이 좋고 사용하기 편리합니다.

★★★☆☆
기능은 괜찮지만 연결이 가끔 끊깁니다.

------------------------------------------------------------

1. 전체 리뷰 보기
2. Gemini AI 리뷰 분석 / 고객 인사이트
3. 부정 리뷰 보기
4. 긍정 리뷰 보기
5. 제품 대시보드
0. 이전 메뉴
```

# 8. AI 기반 감정 분석

사용자가 제품에서 AI 리뷰 분석 기능을 선택하면 해당 제품의 리뷰 텍스트를 Gemini API에 전달합니다.

AI는 각 리뷰를 다음 세 가지 감정으로 분류합니다.

* Positive : 긍정
* Neutral : 중립
* Negative : 부정

또한 AI가 해당 감정 판단을 얼마나 확신하는지 `0.0 ~ 1.0` 범위의 신뢰도 점수를 함께 반환합니다.

예시:

```text
리뷰
"음질은 정말 좋지만 블루투스 연결이 가끔 끊깁니다."

AI 분석 결과
감정 : Negative
신뢰도 : 0.87
```

AI 분석 결과는 메모리에서만 사용하는 것이 아니라 정제된 리뷰 파일에 영구 저장됩니다.

```text
data/clean_reviews.jsonl
```

저장되는 주요 AI 분석 항목은 다음과 같습니다.

```text
sentiment
confidence
analysis_provider
analyzed_at
```

# 9. AI 분석 대상 선택

AI 감정 분석 시 분석할 리뷰의 범위를 선택할 수 있습니다.

### 전체 리뷰 분석

해당 조건에 맞는 리뷰 전체를 분석합니다.

### 특정 리뷰 분석

리뷰 ID를 지정하여 특정 리뷰만 AI 분석할 수 있습니다.

### 미분석 리뷰 분석

아직 AI 감정 분석이 수행되지 않은 리뷰만 대상으로 분석할 수 있습니다.

이를 통해 이미 분석된 리뷰에 대한 불필요한 API 호출을 줄일 수 있습니다.

# 10. API 오류 처리

외부 AI API 사용 중 네트워크 오류 또는 API 오류가 발생할 수 있습니다.

이 경우 전체 프로그램을 중단하지 않고 오류가 발생한 리뷰를 로그에 기록한 후 다음 리뷰 분석을 계속 수행합니다.

주요 로그 레벨은 다음과 같습니다.

* INFO
* WARNING
* ERROR

로그 파일은 다음 위치에 저장됩니다.

```text
logs/app.log
```

# 11. AI 키워드 및 리뷰 요약

리뷰별 감정 분석이 완료되면 여러 개의 리뷰를 종합하여 Gemini AI에 추가 분석을 요청합니다.

주요 추출 항목은 다음과 같습니다.

### 긍정 키워드

고객 리뷰에서 반복적으로 나타나는 제품의 장점을 추출합니다.

예시:

```text
음질
디자인
배터리
사용 편의성
블루투스
```

### 부정 키워드

고객 리뷰에서 반복적으로 나타나는 불편 사항과 문제점을 추출합니다.

예시:

```text
연결 끊김
충전 문제
무게
높은 가격
내구성
```

### 전체 리뷰 요약

여러 고객 리뷰를 AI가 종합하여 제품에 대한 전체적인 고객 반응을 요약합니다.

예시:

```text
전반적으로 음질과 디자인에 대한 만족도가 높으며
사용 편의성 역시 긍정적으로 평가되고 있습니다.

다만 일부 리뷰에서는 블루투스 연결 안정성과
제품 가격에 대한 불만이 나타났습니다.
```

### 개선 제안

부정 리뷰와 반복적으로 나타나는 고객 불만을 기반으로 제품 개선 방향을 제안합니다.

예시:

```text
- 블루투스 연결 안정성 개선
- 제품 가격 경쟁력 검토
- 충전 방식 개선
```

# 17. 고객 별점과 AI 감정 비교

고객 별점과 AI 감정 분석 결과는 서로 다른 값으로 관리합니다.

고객 별점은 고객이 쇼핑몰에서 직접 입력한 평가 점수이고, AI 감정은 실제 리뷰 내용을 AI가 분석한 결과입니다.

예:

```text
고객 별점
★★★★☆ 4점

리뷰
"제품은 괜찮지만 연결이 너무 자주 끊깁니다."

AI 분석
Negative

AI 신뢰도
0.91
```

이를 이용하여 고객이 입력한 별점과 실제 리뷰 내용 사이에 차이가 있는지도 확인할 수 있습니다.

# 27. 제품/브랜드/카테고리 비교 분석

기존 CLI는 제품 하나를 선택해서 리뷰를 분석하는 기능만 제공하고 있었습니다.
하지만 실제로 리뷰 데이터를 활용한 의사결정에서는 "이 제품이 경쟁 제품보다
평판이 좋은가?", "이 브랜드가 저 브랜드보다 만족도가 높은가?" 같은 **비교**
질문이 더 자주 나옵니다.

이번 보너스 과제에서는 여러 제품 또는 브랜드의 리뷰 통계를 나란히 비교하는
기능을 추가했습니다. 다만 전혀 다른 종류의 제품(예: 키보드 vs TV 마운트)을
비교하는 것은 의미가 없으므로, **같은 카테고리(종류)의 제품끼리만 자동으로
묶어서 비교**할 수 있는 기능도 함께 추가했습니다.

# 28. 비교 대상 선택 방식

비교할 대상을 지정하는 방법은 3가지입니다.

### 이름으로 직접 지정

제품명 또는 브랜드명을 쉼표(,)로 구분해서 입력합니다. 이름을 전부 입력하지
않아도, 입력한 글자를 포함하는 후보가 정확히 1개면 자동으로 찾아줍니다.
후보가 여러 개거나 없으면 어떤 후보들이 있는지 안내합니다.

```text
$ python main.py compare --products "CRX-322,Sanus"

[안내] 아래 입력은 매칭에 실패했습니다:
 - 'Sanus': 여러 항목과 일치합니다. 더 구체적으로 입력해주세요.
   후보: Sanus VLF410B1 10-Inch Super Slim Full-Motion Mount for 37 - 84 Inches TV's
```

### 번호로 선택 (쇼핑몰 메뉴)

제품명이 길어서 직접 입력하기 어려운 문제를 해결하기 위해, 대화형 쇼핑몰
메뉴에서는 기존 제품 목록 화면(번호·브랜드·제품명·리뷰수)을 그대로 재사용해서
번호만 입력하면 비교 대상으로 선택할 수 있게 만들었습니다. (자세한 사용법은
4장 참고)

### 카테고리로 자동 선택

제품명 하나하나를 고르지 않고, "스피커"처럼 카테고리 이름만 지정하면 같은
카테고리로 분류된 제품들을 자동으로 모아서 비교합니다. (자세한 내용은
5장 참고)

# 29. 비교 분석 CLI 사용법

`compare` 서브커맨드를 새로 추가했습니다.

```text
python main.py compare --products "제품A,제품B"
python main.py compare --brands "브랜드A,브랜드B"
python main.py compare --category "스피커" --limit 5
python main.py compare --list-categories
```

주요 옵션은 다음과 같습니다.

* `--products` : 쉼표로 구분한 제품명 목록끼리 비교
* `--brands` : 쉼표로 구분한 브랜드명 목록끼리 비교
* `--category` : 카테고리명으로 같은 종류의 제품을 자동으로 모아서 비교
* `--limit` : `--category` 사용 시 비교에 포함할 제품 개수 (기본값 5, 리뷰
  많은 순으로 상위 N개만 선택)
* `--list-categories` : 현재 데이터에서 자동 분류된 카테고리 목록과 제품
  개수만 출력하고 종료
* `--output-dir` : 결과(차트, 리포트) 저장 폴더 지정 (기본값
  `output/compare/`)
* `--no-chart` : 차트를 생성하지 않고 표만 출력

쇼핑몰 메뉴 실행 화면(`python main.py`, 인자 없이 실행)에 "6. 제품/브랜드/

```text
================================================================================
                전자제품 고객 리뷰 AI 쇼핑몰 CLI
================================================================================
  1. 제품 둘러보기
  2. 제품 검색

  0. 종료
================================================================================
```

6번을 선택하면 다시 4가지 방식 중 하나를 고를 수 있습니다.

```text

 2. 제품끼리 비교 (이름 직접 입력)
```

# 31. 카테고리 자동 분류 방식

원본 데이터(`DatafinitiElectronicsProductData_KO_7299.csv`)에는 `categories`
컬럼이 있지만, 태그가 일관성 없이 뒤섞여 있고 기존 파이프라인(`importer.py`,
`cleaner.py`)에도 저장되지 않고 있었습니다. 파이프라인 구조를 바꾸는 대신,
이미 프로젝트에 있는 `analytics.py`의 `theme_counts()`와 같은 방식(키워드
매칭)을 제품명에 적용해서 카테고리를 추정합니다.

```text
거치대/마운트   ← mount, bracket, stand 등
차량용 오디오   ← car speaker, cd receiver 등
헤드폰/이어폰   ← headphone, earbud, earphone
스피커         ← speaker, soundbar, home theater, subwoofer
TV/디스플레이  ← tv, led tv, smart led
키보드/마우스   ← keyboard, mouse, type cover
저장장치/메모리 ← hard drive, memory, ddr
네트워크/통신   ← wi-fi, hotspot, lte
배터리/충전기   ← battery, charger, adapter
카메라/영상    ← camera, camcorder
라디오/리모컨   ← radio, remote
기타          ← 위 키워드에 해당 없음
```

현재 샘플 데이터(50개 제품) 기준 분류 결과는 다음과 같습니다.

```text
$ python main.py compare --list-categories

=== 사용 가능한 카테고리 (제품명 키워드 기반 추정) ===
 - 스피커 (15개 제품)
 - 차량용 오디오 (6개 제품)
 - 헤드폰/이어폰 (5개 제품)
 - 라디오/리모컨 (4개 제품)
 - 기타 (4개 제품)
 - 저장장치/메모리 (4개 제품)
 - 네트워크/통신 (3개 제품)
 - 배터리/충전기 (3개 제품)
 - 키보드/마우스 (2개 제품)
 - 거치대/마운트 (2개 제품)
 - TV/디스플레이 (1개 제품)
 - 카메라/영상 (1개 제품)
```

**참고:** 이 분류는 제품명 키워드로 추정한 결과이며, 원본 카테고리 태그를
그대로 사용한 것이 아니므로 100% 정확하지 않을 수 있습니다. 비교 결과와
리포트에는 "제품명 키워드 기반 추정 카테고리"라는 안내 문구를 함께 표시해서
이 점을 명확히 밝히고 있습니다.

# 33. 비교 분석에서 재사용한 기존 코드

새로운 저장 방식이나 AI 호출을 추가하지 않고, 이미 있는 기능을 조합해서
만들었습니다.

* `storage.filtered()` — 제품/브랜드 조건으로 리뷰를 걸러내는 기존 함수
* `analytics.stats()` — 감정 비율, 평균 별점 등 통계 계산 (기존 `stats`,
  `dashboard` 명령과 동일한 함수)
* `analytics.theme_counts()` — 긍정/부정 테마 키워드 집계 (기존
  대시보드/리포트 기능과 동일한 함수)
* `shop.product_catalog()` — 제품별 리뷰 수, 평균 별점 등 요약 (기존 제품
  목록 화면과 동일한 함수)
* `dashboard.apply_font()` — 차트 한글 폰트 설정 (기존 대시보드 차트와
  동일한 방식)

즉 비교 기능 자체는 AI API를 호출하지 않고, 이미 분석·저장되어 있는
`clean_reviews.jsonl` 데이터만 읽어서 동작합니다.

# 35. 비교 분석 참고 사항

* 카테고리 분류는 제품명 키워드 기반 추정치이며, 원본 CSV의 `categories`
  컬럼을 파이프라인에 정식으로 반영한 것은 아닙니다. 더 정확한 분류가
  필요하면 `config.json` / `importer.py` / `cleaner.py`에 `category` 필드를
  추가하는 방식(공용 파이프라인 수정 필요)을 검토할 수 있습니다.
* 비교 인사이트(평균 별점/긍정 비율 최고·최저 등)는 감정 분석이 완료된
  리뷰가 있어야 계산됩니다. 감정 분석 전이면 안내 메시지만 출력됩니다.
